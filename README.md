# GasyCoder Corporate

Simple corporate website for GasyCoder.

## Stack
- Next.js
- TypeScript
- Tailwind CSS 4
- App Router

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Production

```bash
npm run build
npm start
```
